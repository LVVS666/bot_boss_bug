# Telegram Bug Bot

Бот собирает из тем `Bugs` и `Development` одной Telegram-группы сообщения с
фотографией и тегом `#new_bug`, добавляет их в Google Sheets и удаляет строки
после установки чекбокса `Удалить`. Сообщения из остальных тем игнорируются.

Фото остаётся в Telegram. В таблицу записывается ссылка на исходное сообщение,
доступная участникам группы. Токен бота в таблицу не попадает.

## Формат сообщения

Отправьте фотографию с подписью:

```text
Через кнопку Create Signal появляется ошибка.
Обычная публикация работает.

#new_bug
```

Бот игнорирует сообщения без фотографии или без тега.

## 1. Подготовка Telegram

1. Добавьте бота в группу.
2. В BotFather отключите Privacy Mode через `/setprivacy` → `Disable`.
3. Отправьте сообщение в группу.
4. До запуска бота откройте в браузере:

   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`

5. Найдите отрицательный `chat.id`, обычно начинающийся с `-100`.

Никому не отправляйте токен и полный ответ `getUpdates`.

Темы форума Telegram определяются числовым `message_thread_id`, а не названием.
После первого запуска отправьте команду `/where` отдельно в темах `Bugs` и
`Development`. Бот покажет ID группы и каждой темы. Команда `/where` работает в
любой группе, куда добавлен бот, но сбор ошибок — только в группе и двух темах из
настроек.

## 2. Доступ к Google Sheets

1. Создайте проект в Google Cloud.
2. Включите Google Sheets API.
3. Создайте Service Account и скачайте JSON-ключ.
4. Найдите в JSON поле `client_email`.
5. Откройте Google-таблицу и выдайте этому email права редактора.

Service Account используется только для редактирования таблицы. Фото не
загружаются в Google Drive.

## 3. Локальный запуск

Требуется Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Положите JSON-ключ рядом с проектом под именем `service-account.json`, затем
заполните `.env`:

- `TELEGRAM_BOT_TOKEN` — токен из BotFather;
- `ALLOWED_CHAT_ID` — ID группы;
- `ALLOWED_THREAD_IDS` — ID тем `Bugs` и `Development` через запятую;
- `GOOGLE_SPREADSHEET_ID` — уже заполнен ID переданной таблицы;
- `GOOGLE_SHEET_NAME` — можно оставить пустым, тогда используется первый лист.

Запуск:

```bash
python app.py
```

Для первичной настройки бот может запускаться без `service-account.json`: команда
`/where` будет работать, но сообщения об ошибках не будут записываться в таблицу.
После получения ID тем добавьте Google-ключ и перезапустите процесс.

Чтобы узнать ID тем, при первом запуске можно оставить
`ALLOWED_THREAD_IDS=` пустым. Отправьте `/where` в каждой из двух тем, запишите
полученные ID в `.env`, например `ALLOWED_THREAD_IDS=12345,67890`, и
перезапустите бота. Пока список пуст, бот не добавляет ошибки в таблицу.

## 4. Проверка

1. Отправьте в тему `Bugs` или `Development` фотографию с описанием и
   `#new_bug` в подписи.
2. Бот должен ответить номером записи.
3. В Google Sheets появится строка и чекбокс `Удалить`.
4. Отметьте чекбокс. По умолчанию строка удалится в течение 30 секунд.

Скрытые столбцы `chat_id`, `message_id` и `telegram_file_id` предотвращают
повторное добавление одного сообщения. Номера ошибок не перенумеровываются после
удаления, поэтому остаются стабильными.

## 5. Docker

```bash
docker build -t telegram-bug-bot .
docker run --env-file .env telegram-bug-bot
```

Для хостинга передайте JSON-ключ через секрет
`GOOGLE_SERVICE_ACCOUNT_JSON`. Значение может быть исходным JSON или строкой
base64. Не добавляйте `.env` и JSON-ключ в Git.

Бот использует long polling, поэтому ему не нужен публичный URL или webhook.
Запускайте один экземпляр процесса: несколько экземпляров будут одновременно
получать обновления и проверять чекбоксы.

## Развёртывание

Проект совместим с любым Docker-хостингом, который поддерживает постоянно
работающий worker: Railway, Render Background Worker, Fly.io, Cloud Run с
постоянным экземпляром или обычный VPS.

Для экономичных серверных платформ учитывайте режим сна: если процесс остановлен,
бот не принимает новые сообщения до повторного запуска.

## Текущие ограничения

- В колонке `Фото` хранится ссылка на исходное сообщение Telegram, а не встроенная
  миниатюра.
- Ссылка `t.me/c/...` работает для супергрупп и открывается только у участников.
- Для встроенных фотографий потребуется отдельное постоянное хранилище, например
  Cloudflare R2/S3, либо OAuth-доступ к Google Drive от имени пользователя.
