# Telegram Bug Bot

Бот читает одну заданную тему Telegram-группы и добавляет сообщения с тегом
`#new_bug` в Google Sheets. Фотографии бот не скачивает и не сохраняет: если у
сообщения есть фото, используется только его подпись.

В таблице четыре видимые колонки:

1. `Ссылка на сообщение`.
2. `Описание бага`.
3. `Подтверждение исправления` — чекбокс разработчика.
4. `Исправлено` — чекбокс тестировщика; после установки строка удаляется.

После добавления строки бот отправляет уведомление в тему `DEV_THREAD_ID`. Когда
разработчик устанавливает первый чекбокс, бот отправляет баг в тему
`TESTING_THREAD_ID`. Служебные колонки таблицы скрыты.

## Формат сообщения

В исходной теме отправьте обычный текст или фотографию с подписью:

```text
Через кнопку Create Signal появляется ошибка.
Обычная публикация работает.

#new_bug
```

## Настройка

Требуется Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Положите ключ сервисного аккаунта Google рядом с проектом под именем
`service-account.json`. Сервисному аккаунту нужны права редактора на таблицу, а
в Google Cloud должен быть включён Google Sheets API.

Основные переменные `.env`:

- `TELEGRAM_BOT_TOKEN` — токен из BotFather;
- `ALLOWED_CHAT_ID` — ID группы;
- `ALLOWED_THREAD_IDS` — ровно один ID исходной темы, откуда читать `#new_bug`;
- `DEV_THREAD_ID` — тема разработчиков для уведомлений о новой записи;
- `TESTING_THREAD_ID` — тема тестировщиков для исправленных разработчиком багов;
- `GOOGLE_SPREADSHEET_ID` — ID таблицы;
- `GOOGLE_SHEET_NAME` — имя листа или пустая строка для первого листа;
- `CLEANUP_INTERVAL_SECONDS` — период проверки чекбоксов, минимум 10 секунд.

Если тестировщики находятся в другой группе, задайте
`FIX_NOTIFICATION_CHAT_ID` и `FIX_NOTIFICATION_THREAD_ID`. Иначе для
`TESTING_THREAD_ID` используется исходная группа.

Чтобы узнать ID группы и темы, отправьте `/where` в нужной теме после запуска
бота. В BotFather для бота должен быть отключён Privacy Mode.

## Запуск и проверка

```bash
python app.py
```

1. Отправьте `#new_bug` в исходную тему.
2. Проверьте новую строку в Google Sheets и уведомление в `DEV_THREAD_ID`.
3. Установите `Подтверждение исправления` — бот отправит баг тестировщикам.
4. Установите `Исправлено` — строка будет удалена.

## Docker и хостинг

```bash
docker build -t telegram-bug-bot .
docker run --env-file .env telegram-bug-bot
```

Для хостинга вместо файла можно передать ключ через
`GOOGLE_SERVICE_ACCOUNT_JSON` как исходный JSON или base64. `.env` и JSON-ключ
нельзя добавлять в Git.

Бот использует long polling, поэтому запускайте только один экземпляр процесса.
